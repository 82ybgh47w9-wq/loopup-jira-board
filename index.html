Getting Started
Step 1 — Get your API token
Go to Atlassian API Tokens, click Create API token, name it anything, and copy the token.
Step 2 — Enter credentials
Fill in the form with your Jira URL, email, and the API token you just created.
Step 3 — Select a project group
After connecting, choose a project group (e.g. "Commercial"). Ask your team lead which group to use.
Quick Tips
📌 Active Task — set your current task as "active" so the team can see what you're working on. Keep it up to date!
🔀 Drag & Drop — drag task cards between columns to change status or priority. In Prioritise and My Epics, drag to reorder or move tasks between epics.
➕ Quick Create — hit "+ Create" in the top right. Select a project, type your task name, and AI will suggest the right epic.
👁 Team View — see everyone's tasks at a glance. Great for standups and planning.
